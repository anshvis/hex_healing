# T0.3 - General regression set and baseline scores for the shipped model

## Milestone
M0 - Feasibility spikes and baseline. **Covers:** part of AC-8 (the general set) and AC-9's runner. **Surface:** backend.

## Branch
`healing/m0-feasibility`, base `dev`.

## Objective
Build the fixed general regression set, and record the shipped default model's scores on it with `hex benchmark-transcription`. That gives every later gate and the drift guard (D-12) a reference number.

## Context
- `hex benchmark-transcription <manifest> [--model <gguf>] [--runs N] [--warmups N]` reads `{vocabulary?, clips:[{id, audio, expected, expected_terms?, group?}]}`. It writes JSONL, ending in a `summary` with `wer`, `word_errors`, `reference_words`, `median_rtf`, `p95_clip_ms` and `quality.term_recall` (`src/transcription/benchmark.rs:88-107,222-361`).
- Audio is resampled to 16 kHz.
- The backend is Metal (`src/parakeet.rs:1316`), so this runs on the Mac.
- `docs/plans/transcription-quality.md:37-44` already sketches a LibriSpeech guard set.

## Domain model
Source: inferred.
- **`$HEALING_HOME/sets/general/manifest.json`.** Role: the fixed regression set, in the benchmark manifest format.
  - Each clip has `id` (`ls-<utt>` or `ami-<utt>`), `audio` (a relative 16 kHz WAV path), `expected` (the reference text) and `group: "ordinary"`. The benchmark accepts only `target`, `distractor`, `ordinary` and `private` (`src/transcription/benchmark.rs:391-413`).
  - The source (`librispeech` or `ami`) lives in a sidecar, `sets/general/clips.jsonl` (`{id, source}`), and per-source WER is computed in `healing` from the benchmark's per-clip `word_errors` and `reference_words`.
  - Invariants: the clip list never changes once written; `sets/general/manifest.sha256` pins it.
- **`healing/eval/baseline.json`** (committed). Fields:
  - `model` (catalog id), `gguf_sha256`;
  - `set_sha256`;
  - `wer`, `wer_by_source` (every clip is group `ordinary`, so a per-group WER would say nothing);
  - `median_rtf`, `load_ms`;
  - `hex_binary`, `hex_version`, `hex_binary_sha256`;
  - `hex_sha` (only when the binary is this checkout's release build, else null) and `repo_sha`;
  - `command`;
  - `measured_at`.

## API
Source: inferred.
### `healing sets build-general [--librispeech 300] [--ami 200] [--seed 13]`
- **Output:** writes the manifest, its WAVs and the sha256 file under `$HEALING_HOME/sets/general/`.
- **Errors:** download failure → non-zero exit naming the source. An existing manifest with a different hash → refuse (G-10 spirit).
- **Idempotency:** with the same seed and sources it gives the same manifest hash. An existing identical set is a no-op.
- **Callers:** T3.3 and M7.

### `healing eval baseline [--model <gguf>]`
- **Output:** runs `hex benchmark-transcription` on the general manifest (default `--runs 1 --warmups 1`) and writes `baseline.json`.
- **Errors:** `hex` is not built or found → a clear error. A non-zero benchmark exit → its stderr tail.

## Decisions
- D-11: 300 LibriSpeech test-other plus 200 AMI IHM utterances. Test-other rather than test-clean, because dictation audio is closer to "other".
- AMI segments shorter than 1 s or longer than 20 s are dropped. Very short clips inflate WER noise; very long ones exceed dictation length.

## Watch out for
- **AMI's text normalization** (fillers, disfluency tags). Normalize the reference with the same rules the benchmark uses: read `benchmark.rs`'s normalizer, and strip AMI tags before writing `expected`.
- **Dataset licences.** LibriSpeech is CC BY 4.0 and AMI is CC BY 4.0. Store them under `$HEALING_HOME` and never commit audio.
- **A pinned seed** gives the same slice on any machine.
- **Long runtimes.** 500 clips × 1 run on Metal takes a few minutes. Keep `--runs 1`.

## Acceptance criteria
- The general manifest builds reproducibly (same hash twice). `baseline.json` exists with the shipped default model's WER per group and the exact command.

## Guardrails and exit criteria
- **G-2:** writes only `healing/**`. Audio stays in `$HEALING_HOME`, uncommitted.
- **G-3:** network use only for public dataset downloads.
- **X-4:** the benchmark can't run a model from a path outside Hex's models folder → replan T3.3.
