# T3.4 - `hex benchmark-transcription --vocabulary`

## Milestone
M3 (moved from M4 so T3.3 and the M7 gate can score with your vocabulary). **Covers:** AC-9 (vocabulary in eval), AC-10 (proof of effect). **Surface:** backend.

## Branch
`healing/m3-benchmark-vocabulary`, base `dev`. A Rust PR, separate from the Python one.

## Objective
- `hex benchmark-transcription <manifest> --vocabulary <file.json> [--boost light|normal|strong]` biases the model exactly as dictation does.
- `healing eval` (T3.3) passes your vocabulary with it, and `healing vocab ab` (T4.3) uses it for the Tier 1 A/B.

## Context
- The manifest's `vocabulary` is used for scoring only, "never passed to the model" (`src/transcription/benchmark.rs:89`).
- Dictation biases through `transcription_bias()` → `bias_for` (`src/dictation/vocabulary.rs:273-312`), applied in `gguf_session.rs:208-228` from the global vocabulary and the Labs gate.
- `docs/plans/transcription-quality.md:37` already plans `--vocabulary` for `Parakeet::load_for_benchmark`.

## Domain model
Source: inferred. No store changes.
- The `--vocabulary` file has the same shape as settings: `[{term, sounds_like[]}]` or strings.

## API
Source: edited (`transcription-quality.md` planned it with aliases; this uses the shipped `sounds_like` shape).

### `hex benchmark-transcription … --vocabulary <path> [--boost <level>]`
- Builds the same `(terms, ParakeetVocabularyOptions)` as `bias_for`, through the same function made `pub(crate)` and given a slice, and applies it to every clip's run.
- The default boost is `normal`.
- Without the flag, behaviour is unchanged.
- **Errors:** an unreadable or invalid file → exit 2, naming the field.
- **Callers:** you and `healing`.

## Files to change

- `src/main.rs`: CLI args near `:165-182,579-598`.
- `src/dictation/vocabulary.rs`: expose `bias_for` (pub(crate)) unchanged.

## Gold-star references

## Decisions
- Boost default `normal`, the same as Hex's default (check `VocabularyBoost::default`).

## Watch out for
- **Must not mutate global vocabulary state.** The benchmark process may share the static `BOOST` atomics. Pass the override explicitly.
- **The 64 cut applies in the benchmark too**, so the A/B measures what users get.
- **Leakage:** A/B mining uses `--train-only` (T3.2).
- **Input preparation (found in M0).** The benchmark pads each clip to the minimum duration (`pad_for_parakeet`) but not with Unified's 400 ms of trailing silence, which dictation adds on every OS (`pad_gguf_samples`, `src/transcription.rs:172`; #1629). Switch the benchmark to `pad_gguf_samples` in this PR, so gates score audio prepared the way dictation prepares it. Record the baseline before and after; a shift is expected and is not a regression.

## Acceptance criteria
- A manifest with a clip saying "Qorvyx" (T0.4's synthetic set) misses with no vocabulary and hits with `--vocabulary` containing `{term:"Qorvyx", sounds_like:["corvix"]}`.
- Without the flag, output is byte-identical to before (excluding timings).

## Guardrails and exit criteria
- **G-5:** the benchmark is a dev tool and no user behaviour changes.
- **X-4:** if the bias can't be passed per run without changing transcribe.cpp, stop.
