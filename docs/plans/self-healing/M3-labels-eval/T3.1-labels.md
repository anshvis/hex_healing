# T3.1 - Labels and weights

## Milestone
M3. **Covers:** AC-7. **Surface:** backend.

## Branch
`healing/m3-labels-eval` (one PR for M3), base `dev`.

## Objective
Every clip gets a label and a training weight:

| Label | When | Weight |
|---|---|---|
| `strong` | at least one acoustic edit; the reference is `reference_text` | 1.0 |
| `verified` | you confirmed the reference in a review | 1.0 |
| `weak` | observed `unchanged` 30 s after the paste | 0.2, and excluded from training by default (`--include-weak` to use it) |
| `unlabelled` | never observed (lab off, or `lost`) | 0 |

A clip is trainable only if all of these hold:
- it has audio;
- its `model` equals the model it is compared against, or the reference is a corrected or verified human reference, which is model-independent;
- its kind is `dictation`;
- it isn't `golden`.

## Context
- The brief: corrected clips are strong labels. Untouched clips are weak labels; give them less weight, or leave them out at first.
- Weak references are the current model's own output. So are a strong clip's **untouched** words (challenge finding 8): `reference_text` is `raw_text` with only your acoustic edits applied. Scoring either in test sets would favour the model that wrote them.
- So **gating test sets use only `verified` references** (AC-7). Strong clips are scored only at their edited positions (T3.3), and they remain full-weight **training** labels.

## Domain model
Source: inferred.

### `clips` (columns this task touches)
- `label` TEXT, with the transitions:
  - `unlabelled` → `weak` (observed unchanged)
  - `unlabelled` or `weak` → `strong` (acoustic edit)
  - any → `verified` (review)

  A label is a function of its evidence (`labels.refresh` is the only writer; `collect` and `label corrections` never write it), so a strong clip whose correction changed is `unlabelled` until it is classified again. Rejecting a clip in a review lowers it and clears its reference. An acoustic edit beside an unmapped one leaves the clip `unlabelled`.
- `weight` REAL NOT NULL DEFAULT 0
- `reference_text` TEXT NULL: for strong it's from T2.4; for verified it's the reviewed text; for weak it's `raw_text`.
- `edited_positions` JSON NULL: for strong clips, the token spans of `reference_text` that you edited (from T2.4's `edits`).
- `review_strategy` TEXT NULL: `random` or `uncertain`, recorded on each review.

### `reviews` (new)
- Columns: `review_id` (autoincrement; a later review replaces an earlier one), `clip_id`, `reviewed_at_ms`, `action` (accept, fix or reject), `text`, `strategy` (`random` or `uncertain`).
- Feeds both `verified` and the golden set (T3.2).

## API
- **`healing label all`:** recomputes labels and weights from corrections and reviews. Idempotent.
- **`healing review [--n 20] [--strategy random|uncertain] [--since-cutoff]`:** `random` is the default and the only strategy that feeds gating sets (T3.2). `uncertain` feeds training only.
  - plays each clip with `afplay` and shows `raw_text`;
  - Enter accepts, typing replaces the text, `r` rejects;
  - writes `reviews`.
  - `uncertain` picks weak clips with the lowest model confidence if the benchmark exposes it; otherwise the most recent.

## Decisions
- Weak weight 0.2 and excluded by default, per the brief ("or leave them out at first").
- A rejected review → `label=unlabelled`, `weight=0`, and the clip is never trainable. For a clip that's noise, a cough, or someone else talking.

## Watch out for
- **A clip with a correction whose edits are all `rewrite`** stays `weak`. You changed your mind but didn't fix a mishearing, so the speech was transcribed right.
- **`unmapped` edits** make the clip `unlabelled`. Don't trust it.
- **A clip whose audio was evicted** can be strong but not trainable. It still counts for Tier 1.
- **`model` is null on old entries:** usable only with a human reference.
