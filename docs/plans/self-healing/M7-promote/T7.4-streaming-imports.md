# T7.4 - Hex: an imported fine-tune of a streaming model can stream

## Milestone
M7. **Covers:** AC-13 (the `streaming` check). **Surface:** full-stack (a Labs card plus model loading).

## Branch
`healing/m7-streaming-imports`, base `dev`. A Rust PR of its own.

## Objective
Today every imported model is built with `streams: false` (`src/transcription/custom_models.rs:348`). The catalog's Parakeet Unified English has `streams: true` (`src/transcription/models.rs:412-421`). A promoted fine-tune would silently lose live streaming: dictation waits for the whole clip after release, and Labs › Live text stops (challenge finding 13).

This task adds Labs › **Stream imported models** (`stream-imported-models`, off by default, D-26). With it on, an import streams when both hold:
- its GGUF header's architecture and `stt.variant` equal a streaming catalog model's;
- a stream smoke test passes when the model is first selected.

## Context
- Streams run only on GPU devices, and models that can't stream transcribe the whole clip (AGENTS.md streaming invariant).
- Imports are checked from their header alone (`gguf_header.rs`, `custom_models.rs:567-640`).
- A fine-tune keeps the base's variant (T0.4 asserts identical tensor names).

## Domain model
Source: inferred.

### Custom model manifest `models/custom/<16hex>.json`
- **Columns touched:** `streams_like: Option<String>`, the catalog id whose architecture and variant match. Set at import from the header.
- **Before → after:**
  - before: `{…, family:"parakeet", variant:"<unified variant>"}`
  - after: `{…, streams_like:"parakeet-unified-en"}`

### `settings.json` `labs.stream_imported_models`
- bool, default false.

### `ModelDefinition.streams` for a custom model
- `= labs::stream_imported_models() && streams_like.is_some() && stream_smoke_ok`.

## API
- **`custom_models::build`:** sets `streams` as above. `stream_smoke_ok` is cached per import id after the first successful 2 s stream on a fixture clip, run once at activation on the engine thread.
- **`hex model list --json`:** adds `streams` per model (additive).
- **Callers:** model activation (`transcription/preparation`), the engine's stream start, and the picker. Check with `rg -n '\.streams' src`.

## Decisions
- **D-26 (agent default):** behind a Lab, off by default (AGENTS.md rule for new behaviour). The M7 gate's `streaming` check fails while the lab is off, telling you to turn it on. *Instead:* make streaming the default for imports whose variant matches a streaming catalog model.

## Watch out for
- **A smoke stream that fails** (a GPU error, say) → the model falls back to whole-clip, logged. It is never broken mid-dictation.
- **The variant matches but the tensors are wrong:** the header check already refuses a mismatched tensor set at import.
- **CPU-only devices** never stream, imports or not (an existing rule).

## Acceptance criteria
- With the lab on, T0.4's merged Unified Q8_0 import reports `streams: true` in `hex model list --json`, and a dictation produces live partials (`/dictations` with `partials: true` on macOS, or the Live text lab).
- With the lab off, `streams: false`.
