# T7.1 - The promotion gate (paired statistics)

## Milestone
M7. **Covers:** AC-13. **Surface:** backend.

## Branch
`healing/m7-promote` (one PR for M7), base `dev`.

## Objective
`healing gate <candidate>` scores the candidate and current models together. It uses `healing eval` (T3.3) with your current vocabulary (T3.4). It passes only when every D-12 check holds.

All intervals are 10,000-resample paired bootstraps over **clips** (Δ = Σerrors / Σwords), reusing T0.1's `healing stats`:

| Check | Pass when |
|---|---|
| `evidence` | rolling has ≥ 1,500 reference words and ≥ 20 term clips |
| `rolling_wer` | the 95% CI upper bound of Δ WER (cand − cur) is below 0 |
| `terms` | an exact McNemar test on per-clip term hits favours the candidate, p < 0.05 |
| `general_wer` | the CI upper bound of Δ WER is below +0.5 pt |
| `golden_wer` | the CI upper bound of Δ WER is below +0.5 pt (skipped until golden freezes) |
| `formatting` | the CI upper bound of Δ formatting error rate is below +0.5 pt |
| `drift_guard` | candidate general WER ≤ v0 general WER + 1.0 pt |
| `streaming` | the candidate streams in Hex (T7.4) and p95 time to text on long clips is within +50 ms of the current model |

The edited-span diagnostic is reported but doesn't gate.

## Context
Changed after the challenge (findings 12–15):
- **Point margins of 0.3 pt / 5% sit inside the noise.** At around 1,000 words, the per-model standard error is about 1 pt, and term error moves 5 pt per clip.
- **Formatting is invisible to the benchmark's WER** (`src/transcription/benchmark.rs:505`).
- **Imports don't stream by default** (`src/transcription/custom_models.rs:348`).
- **The gate must score with the vocabulary you run.** Without it, scores don't reflect your setup.

## Domain model
Source: inferred.

### Registry events
- `{event:"gate", version, against, eval_id, checks:[{name, estimate, ci_low, ci_high, p, threshold, pass}], pass, margins_sha}`
- then `rejected(reason = the first failing check names)` when it fails.

### `healing/gate.toml`
The D-12 thresholds, resample count and seed, versioned in the repo. Its sha is copied into each gate record.

## API
- **`healing gate <v> [--against current]`:** exit 0 when it passes, 7 when it fails. Prints the check table with estimates and intervals.

## Decisions
- D-12 (revised) and D-22: gating sets need your random-sample reviews. With too little evidence, the gate refuses to promote. It never promotes on thin data.

## Watch out for
- **Seeded resampling.** The same eval gives the same decision.
- **Current is v0** (the catalog model): read its GGUF path from `hex model list`, cross-checked with the registry's pinned sha (T5.1).
- **Golden pending:** `golden_wer` is `skipped` (recorded), not passed.
- **`--allow-thin-evidence`** exists only for fixtures and is refused outside tests.

## Acceptance criteria
- **AC-13 (gate):**
  - each check, made to fail alone in a fixture eval, fails the gate with only that check named;
  - a true 3-pt improvement on 2,000 words passes;
  - a 0.3-pt "improvement" on 600 words fails `rolling_wer` (the CI straddles 0);
  - a punctuation-stripping candidate fails `formatting`;
  - a non-streaming candidate fails `streaming`.

## Guardrails and exit criteria
- **G-3:** offline. Eval runs in Hex's local runtime.
- **G-10:** the golden check refuses when the golden hash differs from its pin.
- **X-4:** a benchmark output shape change → stop.
