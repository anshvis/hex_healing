# T1.5 - `healing clean`: keep the audio index true and the disk from filling

## Milestone
M1 - Long-term capture. **Covers:** AC-4. **Surface:** backend.

## Branch
`healing/m1-clean`, base `healing/m1-storage-budget`.

## Objective
Every audio file the pipeline writes is indexed, and nothing it writes can fill the disk:
- **The index matches the disk.** Every FLAC in `$HEALING_HOME/audio/` has a row, and every row with audio points at a file whose size and SHA-256 match.
- **Free space has a floor.** Below the floor, collection stops adding audio and prune tightens the budget until the floor holds.
- **Leftovers are swept:** temp files, interrupted writes, and anything else the pipeline leaves behind.

`healing collect` runs it after `prune`, so the launchd job (T1.4) keeps it all bounded without you.

## Context
- T1.3 bounds the dataset by a byte budget, but it trusts the index. A crash between writing a FLAC and committing its row, or a file deleted by hand, makes the index lie. Then the budget counts the wrong bytes.
- This Mac has about 35 GB free. A fixed 5 GiB budget is safe today, but not if the disk fills from elsewhere.
- Training (M6) writes about 10 GB of scratch a round. T6.4 removes a round's scratch when the round ends. This task's sweep also catches a round that crashed.

## Domain model
Source: inferred (adds to T1.2's store and T1.3's `audio`).
- **`audio.sha256` and `audio.bytes`:** already written by T1.2. Now checked.
- **`clean_runs`:** `{at_ms, orphans_moved, missing_marked, mismatched_marked, temp_removed, freed_bytes, free_bytes_after}`.
- **`$HEALING_HOME/quarantine/<at_ms>/`:** where orphan files are moved, never deleted, and kept for 7 days.

## API
Source: inferred.

### `healing clean [--dry-run] [--min-free 10GiB] [--deep]`
- **Order:**
  1. Remove `*.tmp` and partial files older than 1 hour under `$HEALING_HOME`.
  2. **Orphans:** move FLACs with no row to `quarantine/`.
  3. **Missing:** set `evicted_at_ms` and `missing: true` on rows whose file is gone. The row and text stay.
  4. With `--deep`, re-hash every file. A mismatch is marked `corrupt`. Without it, only the size is checked, which is fast.
  5. Empty quarantine folders older than 7 days.
  6. Remove M6 round scratch (`$HEALING_HOME/rounds/<id>/work/`) whose round isn't running (no lock) and is more than 1 day old.
  7. **Free-space floor:** if free space on `$HEALING_HOME`'s volume is under `--min-free`, run `prune` with the budget lowered by the shortfall. Protected clips are still never evicted.
- **Output:** one summary line of counts and bytes, also appended to `clean_runs`. With `--dry-run`, the list of what it would do.
- **Errors:**
  - protected audio alone keeps free space under the floor → exit 4, naming the shortfall. Collection keeps text but stops copying audio until it clears.
- **Side effects:** moves orphans, deletes temp files and old quarantine, removes stale round scratch, and updates rows.
- **Idempotency:** a second run right after the first finds nothing.
- **Callers:** `healing collect` (after `prune`), and you.

## Decisions
- **D-35:** orphans are moved to quarantine, not deleted. A file with no row might be the only copy of a clip whose row was lost.
- **The 10 GiB floor** leaves room for one training round's scratch (about 10 GB, M6).
- **Hex's own WAVs are never touched (G-6).** Hex caps Keep recordings at 512 MiB itself.

## Watch out for
- **Collect is mid-write.** Clean runs under the same lock as `collect` and `prune` (T1.3), and skips temp files younger than 1 hour.
- **Free space on APFS** includes purgeable space. Use `statvfs` available blocks, and record which number was used.
- **Never follow symlinks out of `$HEALING_HOME`.**

## Acceptance criteria
- **AC-4 (index):** with a fixture store holding 1 orphan FLAC, 1 row whose file was deleted, 1 corrupted file and 2 stale temp files, `healing clean --deep`:
  - quarantines the orphan;
  - marks the missing and the corrupt rows;
  - removes the temp files;
  - finds nothing on a second run.
- **AC-4 (floor):** with free space faked under the floor, clean evicts weak audio until the floor holds, and evicts no protected clip. With only protected audio left, it exits 4.

## Guardrails and exit criteria
- **G-6:** touches only `$HEALING_HOME`. A test points it at a tree with a symlink to outside and asserts nothing outside changes.
- **G-4:** the clean log has counts and bytes only, never text.
