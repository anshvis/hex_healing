# T8.5 - Training boundary: tidy events, the M2 baseline, and labels

## Milestone
M8. **Covers:** AC-16, AC-17 (data side). **Surface:** backend (History metadata, M2's watcher, `healing`).

## Branch
`healing/m8-tidy`.

## Objective
- **Tidy never trains the speech model on tidied text (D-38):**
  - the dataset's `raw_text` stays what Hex heard;
  - M2's correction capture doesn't mistake a tidy edit for a correction.
- **The decisions feed T8.2:**
  - every accepted or skipped suggestion is recorded;
  - an accepted `misheard` replacement becomes a weak correction label, under M2's survival rules.

## Domain model
Source: inferred.
- **History entry:** `tidy: [{kind, token, accepted, source}]`. Here `token` is the removed or replaced phrase, at most 32 bytes, and holds no surrounding text. Bounded like other History metadata.
- **`hex history --json` row:** a `tidy` array, omitted when empty. `version` stays 1 (additive).
- **Dataset (`healing collect`):**
  - a `tidy_events` table `{clip_id, kind, token, accepted, source}`;
  - `raw_text` and `final_text` unchanged;
  - after a tidy, a new `tidied_text` column holds the text Hex applied.
  - T8.2 already reads `tidy_events` (D-66): `kind` in snake case (`filler`, `repeat`, `self_correction`, `misheard`), `accepted` 0 or 1, timed by the clip's `timestamp_ms`.

## API
- **M2's watcher:** when a tidy applies, the baseline it compares against becomes the tidied text. Corrections are measured from there. A tidy that returns `Moved` changes nothing.
- **Labels (M3):**
  - `misheard` replacements that were accepted and survive M2's window become `weak` corrections, with `source: tidy`;
  - removals never become labels.

## Files to change
- `src/history.rs` (the `tidy` field), `src/control/transcript_cli.rs` (the row), `src/dictation/tidy/apply.rs` (record decisions), M2's watcher module

- tests in each

## Watch out for
- **Tidy before M2's window closes:** the watcher keeps the dictation and resets its baseline. It must not record the tidy diff as your correction.
- **Older entries** have no `tidy`. Omit it.

## Acceptance criteria
- **AC-16 / AC-17 (data):**
  - after a tidy that removes "um" and replaces "Kip" → "Kit", the clip's `raw_text` still has "um" and "Kip";
  - `tidy_events` has both decisions;
  - M2 records no correction for the "um" removal;
  - the "Kit" replacement is a weak label once it survives.

## Guardrails and exit criteria
- **G-4:** tokens only, bounded. No new free text in History.
