# T8.2 - Personal habits

## Milestone
M8. **Covers:** AC-16. **Surface:** backend (`healing` plus a small Rust read).

## Branch
`healing/m8-tidy`.

## Objective
Learn which fillers and verbal habits you accept removing, so suggestions match you:
- a word or phrase you accept removing most of the time is suggested, and ranked first;
- one you usually skip stops being suggested.

## Context
- T8.5 records every tidy decision (accepted or skipped, with kind and token, no surrounding text) in the dataset.
- M1's dataset has `raw_text` for every dictation, which shows how often you say each candidate phrase.

## Domain model
Source: inferred.
- **`tidy_habits`:** `{phrase, shown, accepted, skipped, last_seen_ms}`.
- **The exported list** `$HEALING_HOME/tidy/habits.json` holds phrases with `accept_rate ≥ 0.7` over at least 5 showings. Hex reads it as `habits` for T8.1.
- **Candidate phrases:** a fixed starter list ("like", "you know", "basically", "actually", "kind of", "sort of", "I guess"), plus phrases frequent in your `raw_text` that you removed by hand after a paste (from M2).

## API
- **`healing tidy habits [--json]`:** prints the table and writes `habits.json` atomically (0600).
- **Hex:** reads `habits.json` from a path set by `hex settings set tidy.habits_file`. It's read at each tidy, and a missing or invalid file means no habits.

## Files to change
- `healing/healing/tidy.py`, `healing/healing/cli.py`, `healing/tests/test_tidy_habits.py`
- `src/dictation/tidy.rs` (load habits), plus the settings key and its CLI key (AGENTS.md: every persisted setting has a `hex settings` key).

## Watch out for
- **Context matters:** "like" as a filler versus a verb. A habit removes only matches the rule pass flags as filler-position (comma-delimited, or at a clause start). It is never removed everywhere.
- **Decay:** decisions older than 90 days count half, so changing habits are followed.

## Acceptance criteria
- **AC-16:** with a fixture of decisions where "basically" is accepted 8 of 10 times and "actually" 1 of 10:
  - `habits.json` has "basically" and not "actually";
  - T8.1 suggests "basically" in filler position and doesn't suggest "actually".
