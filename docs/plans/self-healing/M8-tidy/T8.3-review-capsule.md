# T8.3 - Labs › Tidy after paste: trigger and review capsule

## Milestone
M8. **Covers:** AC-17. **Surface:** frontend (Rune capsule, goldens) and backend (Labs, shortcut, control command).

## Branch
`healing/m8-tidy`.

## Objective
Add Labs › Tidy after paste (`tidy-after-paste`): audience Everyone, off by default, group Dictation, macOS first. While it's on:
- **Triggers:**
  - a Tidy shortcut (unbound by default, like Dictate without processing);
  - a "Tidy last dictation" item in the menu bar;
  - `hex dictation tidy`.
- **What a trigger does:** opens a review capsule for the last pasted dictation.
- **The capsule:**
  - shows the pasted text with each suggestion struck through or replaced;
  - lets you toggle each suggestion, with Accept all and Cancel;
  - Return applies and Escape cancels.

## Context
- AGENTS.md: new behaviour lands in Labs, off by default, gated where its work starts. The capsule follows `docs/design-system.md` and `rune_ui/controls.rs`, and its scene gets light and dark goldens.
- Suggestions come from T8.1, computed when the trigger fires and never at paste time (D-37).

## Domain model
Source: inferred.
- **`TidySession`:**
  - `dictation_id` (the History entry);
  - the T8.1 suggestions;
  - per-suggestion `accepted: bool`, default true for rule suggestions and false for model `misheard` suggestions;
  - `opened_at`.

  One session at a time. A new dictation closes an open session.

## API
- **`hex dictation tidy [--print]`:** opens the capsule. `--print` prints the suggestions as JSON without applying them. Through `/control`; `docs/cli.md` is updated.
- **The labs feature:** add it to `labs::Feature` with its settings key, description and group, and a card. Settings keys: `labs.tidy_after_paste` and `tidy_hotkey`.

## Watch out for
- **The capsule takes keyboard focus only while open.** Closing it returns focus to the app that had it, so T8.4 edits the right field.
- **A dictation that only copied, never pasted** (a copy fallback or `--print`): Tidy offers "Copy tidied text" instead of applying.
- **No suggestions:** the capsule says so and closes itself after 1.5 s.
