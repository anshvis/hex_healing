# T8.1 - Suggestion engine

## Milestone
M8. **Covers:** AC-15. **Surface:** backend (a pure Rust module plus the macOS model bridge).

## Branch
`healing/m8-tidy`.

## Objective
`dictation::tidy::suggest(pasted, raw, habits) -> Vec<Suggestion>` returns edits to the pasted text. Each edit is anchored to an exact range of the pasted text, and each is one of:
- **remove** a filler, a stutter or repeat, or the abandoned part of a self-correction;
- **replace** a misheard word with a short alternative.

It never adds content, reorders, answers or summarizes.

## Context
- `src/dictation/apple_cleanup.rs` already has an on-device model call (2 s budget) and a pure guard, run before the paste. Reuse the bridge and the guard's rules. Don't add a second model client.
- Off macOS, or without Apple Intelligence, only the rule pass runs.

## Domain model
Source: inferred.
- **`Suggestion`:**
  - `range` (UTF-16 offsets in the pasted text, which is what Accessibility uses, plus scalar offsets);
  - `kind` (`filler | repeat | self_correction | misheard`);
  - `replacement` (empty for a removal);
  - `source` (`rule | model`);
  - `confidence`.
- **Invariants:**
  - ranges don't overlap;
  - applying every suggestion leaves a subsequence of the original words, plus at most one replacement word per `misheard` edit;
  - `pasted` itself is never stored.

## API
- **Rule pass (every OS):**
  - fillers from a built-in list (um, uh, erm, er, hmm), plus `habits` from T8.2;
  - immediate word repeats;
  - self-correction cues ("scratch that", "no wait", "I mean", "sorry,") followed by a phrase of the same kind, removing the cue and the abandoned phrase.

  The cue rules are conservative: "I mean" as an ordinary phrase must not trigger.
- **Model pass (macOS, Apple Intelligence available):** ask for edits as a JSON list of `{find, replace}`. Each `find` must occur exactly once in the pasted text, or the edit is dropped. Then run the guard.
- **Merge:** rule and model suggestions are deduplicated by range. On overlap the rule wins, because it is exact.

## Watch out for
- **Fillers that carry meaning:** "like" as a verb, "so" at a sentence start that the speaker wants. Built-in removals are only true fillers; habits (T8.2) add the rest per person.
- **Capitalization and punctuation after a removal at a sentence start:** fix the case of the next word, and drop orphaned commas.
- **Non-English dictations:** the rule list is English only. Other languages get the model pass alone.

## Acceptance criteria
- **AC-15:**
  - "um so I think we should, uh, send it Tuesday, scratch that, Wednesday" → removals for "um", "uh" and "Tuesday, scratch that,", giving "So I think we should send it Wednesday."
  - "I mean it" → no suggestion.
  - A model answer that adds a word is dropped by the guard.
