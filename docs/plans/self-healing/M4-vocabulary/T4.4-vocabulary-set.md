# T4.4 - `hex vocabulary set --file`: an atomic, ordered write

## Milestone
M4. **Covers:** AC-10 (apply). **Surface:** backend (CLI, settings).

## Branch
`healing/m4-vocabulary-set`, base `dev`. A Rust PR of its own.

## Objective
`hex vocabulary set --file <path.json>` replaces the global vocabulary list in one settings save, in the file's order, through the running Hex. Mined terms can then be reordered without a run of N `add` and `remove` calls, each of which is its own save and leaves a half-written biased set while it runs (challenge finding 21).

## Context
- `hex vocabulary list|add|remove` goes through the running Hex's `/control` (`src/control/cli.rs:393-410`, handler `src/control.rs:1011`, `docs/cli.md:71,240`).
- The list is `vocabulary` in settings (`src/app_settings.rs:2366-2385`): up to 500 entries, terms and spellings of 64 characters or fewer, up to 16 spellings per term (`src/dictation/vocabulary.rs:19-55`).
- AGENTS.md: every command runs through the app's own paths (the window's settings save, then `ReloadSettings`). Commands are idempotent (`changed: false`). A protocol change that breaks a shape bumps `CONTROL_VERSION` and `docs/cli.md`.

## Domain model
Source: inferred.
- **`settings.json` `vocabulary`:** replaced as a whole. Validated with the same rules as `add`, all or nothing.
- **Before → after:**
  - before `[A, B, mined1]`, file `[A, B, mined2, mined1]` → after exactly the file's list.

## API
- **`hex vocabulary set --file <path> [--json]`**
  - A new `ControlRequest` variant. It is additive, so `CONTROL_VERSION` is unchanged unless an existing shape changes.
  - **Errors:**
    - an invalid entry → `invalid-vocabulary` naming the index and the rule, with nothing saved;
    - Hex isn't running → the standard error;
    - a policy-locked setting → refusal.
  - **Idempotency:** the same list → `changed: false`.
  - **Callers:** `healing vocab apply` (T4.2), and you.

## Watch out for
- **Over 500 entries** → refuse. Don't truncate.
- **Duplicate terms** in the file (case-insensitive) → refuse.
- **Mode vocabularies** are untouched. This sets only the global list.

## Acceptance criteria
- Setting a 5-term list in a new order persists exactly that order in one save.
- An invalid entry saves nothing.
- Setting the same list again replies `changed: false`.

## Guardrails and exit criteria
