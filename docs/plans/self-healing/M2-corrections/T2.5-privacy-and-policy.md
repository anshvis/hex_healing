# T2.5 - Privacy review, AGENTS.md invariant, `DisableCorrections` policy, feature map

## Milestone
M2 - Correction capture. **Covers:** AC-5 (the policy lock), G-4, G-5. **Surface:** backend (policy, docs).

## Branch
`healing/m2-corrections`. It lands in the same PR as T2.1–T2.3, and before them in commit order.

## Objective
Before Hex reads text you typed into other apps, write down exactly what it reads, what it keeps, and for how long. Then:
- amend the AGENTS.md invariant that History keeps "only successful pasted output";
- add a managed-preference lock, `DisableCorrections`, so an administrator can forbid the feature;
- add the feature-map entry AGENTS.md requires for user-facing features.

## Context
- Challenge finding 7: AGENTS.md (`:1044`) says History records "only successful pasted output: raw and final text plus bounded metadata". `edited_text` is text the user typed, and the watcher reads up to 8 KiB of field text into memory.
- `src/policy.rs` holds the `anomaly.hex` managed-preference locks: `Lock::ALL` (`:41`), `key()` (`:51-57`), `refusal()` (`:67`), `labs_lock(feature)` (`:142`), `setting_lock(name)` (`:156`).
- AGENTS.md "Feature Map" requires `docs/features/` updates in the same change.

## Domain model
Source: inferred.

- **Before:** "records only successful pasted output: raw and final text plus bounded metadata".
- **After:** the same, "plus, with Labs › Learn from corrections on, the edited span read back from the field it was pasted into, bounded to 2 × the pasted length + 64 characters, under the same retention, caps, Delete and Clear all".

## Decisions
- D-24: a dedicated lock as well as `DisableLabs`. The feature reads other apps' text, which is a different risk from the other labs.

## Watch out for
- **`Lock::ALL` length** is used in tests and bit packing. Check that `bit()` still fits in its `u8`, with 7 locks.
- **A locked switch reads off** at load and keeps its saved value on save (the AGENTS.md `policy` rule).
