# T2.1 - The `learn-from-corrections` lab and the paste-target handoff

## Milestone
M2 - Correction capture. **Covers:** AC-5 (gate and target). **Surface:** full-stack (Labs card plus the paste worker).

## Branch
`healing/m2-corrections`. One PR for T2.1–T2.3 (all Rust), base `dev`.

## Objective
- Add Labs › Learn from corrections: macOS, Everyone, off by default, group Dictation.
- When it's on and a paste succeeds, hand a `PasteTarget` (pid, retained AX element, History entry id, pasted text) to a correction watcher.

When it's off, nothing is retained or scheduled.

## Context
- `Paster::paste(&mut self, text, mode)` (`src/paste.rs:225`) has no completion hook.
- The completion point is `src/parakeet.rs:1096` (paste), then `:1120` (`last_transcript`), then `:1128` (`record_history`).
- `record_history` throws away the `Option<u64>` id that `History::record` returns (`src/parakeet.rs:1234`, `src/history.rs:398`).
- `frontmost_pid()` is `src/dictation/context.rs:546`.
- AX elements are wrapped by `CfObject`, which already retains and releases (`src/accessibility.rs:435,511-529`). No element outlives a single read today.
- `Paster::paste` **rewrites the text** before inserting it: continuation `join` (case of the first letter, a space) and Labs smart spacing (`src/paste.rs:240-245,669-684`). The text that lands in the field is not always `final_text` (challenge finding 5).
- New labs follow `CursorContext` across about 12 files (see Files).

## Domain model

### `settings.json` `labs.learn_from_corrections`
- bool, default `false`.
- Read by `labs::learn_from_corrections()` (atomic).

### `PasteTarget` (in memory only, never persisted)
- `pid: i32`
- `element: RetainedElement` (CFRetain'd `AXFocusedUIElement` read **before** ⌘V)

- `pasted_at: Instant`
- `secure: bool`: the field is skipped if secure.

## API
Source: inferred.
- **`accessibility::focused_element(pid) -> Option<RetainedElement>`**
  - Errors: `None` for Hex's own pid, a secure field, or an AX timeout (0.25 s).
  - Side effects: none.
- **`correction_watch::submit(target: PasteTarget)`**
  - Queue: bounded (8). Overflow drops the oldest and logs `correction watch dropped` with a count only.
  - Callers: `parakeet.rs` after a successful paste and `record_history` returning `Some(id)`, only while `labs::learn_from_corrections()` holds.
- **`record_history(...) -> Option<u64>`**: the signature changes to return the id. Callers: one (`parakeet.rs:1128`). Check with `rg -n 'record_history\(' src`.

## Decisions
- Should the element be read before or after ⌘V? Before. After the paste, focus may already have moved because of the paste itself, as with chat apps that send on paste.
- What about Send-kind dictations (Labs YOLO presses Return)? Skip them, because the text has left the field.
- What about Chromium apps that get the text typed (`src/paste.rs:239-250`)? Treat them the same. The element is the same.

## Watch out for
- **Releasing the element on every path:** dropped queue item, lab turned off, Hex quit. `RetainedElement::drop` calls CFRelease exactly once.
- **The AX call on the paste path** must not delay the paste by more than its 0.25 s timeout. Read it on the same worker before `paste`; the worker already waits on `PASTE_SETTLE_DELAY`.
- **The lab turned off while targets are queued:** drain them without reading.
- **Copy-only outcomes** (paste failed, microphone-loss copy): no target.
- **`hex dictation stop --print`** pastes nothing, so there is no target.

## Acceptance criteria
- With the lab off, the watcher queue receives nothing for a paste (a test counts submissions).
- With it on, one successful paste submits exactly one target, carrying the History entry id.
- The Labs card renders in both themes.

## Guardrails and exit criteria
- **G-5:** off by default. The gate sits at submission, not just in the UI.
- **G-4:** no text in logs. `PasteTarget` is never serialized.
- **G-9:** goldens are regenerated in this PR.
- **X-4:** if `RetainedElement` can't be made `Send` safely, stop and replan. The alternative is re-finding the element by pid and role.
