# T6.5 - NeMo LoRA training loop

## Milestone
M6. **Covers:** AC-12. **Surface:** backend.

## Branch
`healing/m6-training`.

## Objective
`healing/healing/train/lora.py` does the following:
1. Loads the base `.nemo` for the M0-chosen architecture.
2. Attaches LoRA (rank 16, alpha 32, dropout 0.05) to the encoder's attention q/k/v/out and feed-forward linears and the joint's linears (D-31: the predictor is an LSTM and stays frozen).
3. Freezes everything else.
4. Trains on T6.1's bundle with a `WeightedRandomSampler`.
5. Saves the LoRA delta alone (`safetensors`), plus a train log of loss and validation WER only, with no text.

## Context
- Promotes T0.4's proven `lora_tiny.py` attach and merge code instead of rewriting it.
- **The Mac's CPU is the default target (D-34).** M0 trained at about 5× real time on CPU. A round of 200 minutes of new speech plus as much replay is about 3–4 hours, an overnight job. NeMo's RNN-T/TDT loss is unreliable on MPS (challenge finding 20), so not the GPU.
- The same entry point runs on CUDA for the Kaggle fallback (T6.2).

## Domain model
Source: inferred.
- **Config `healing/train/configs/lora.yaml`:** base sha, LoRA targets, lr 1e-4, epochs 3, batch 16, seed, max steps, early stopping on a 5% validation slice of train (never a test set). The whole file is hashed into the registry.
- **Outputs:** `out/lora_delta.safetensors` and `out/train_log.json`.

## API
- **`healing train --local [--smoke] [--config lora.yaml] --bundle <path>`**
  - Runs under `caffeinate -i`, so the Mac doesn't sleep mid-round.
  - Checkpoints the LoRA weights and optimizer every 200 steps under `rounds/<id>/work/`, and resumes from the last checkpoint when rerun after a crash, sleep or Ctrl-C.
  - Batches by total audio seconds (default 60 s per batch on CPU), not clip count, so long dictations don't run out of 16 GB of memory.
- **`healing train --remote …`** (T6.2) runs the same entry point on the GPU.

## Watch out for
- **Target module names differ between Unified and TDT v2.** Resolve them from the loaded model, and fail if any target matches zero modules.
- **Memory:** measure peak RSS on the longest 30 s clips in the smoke run. Fail the round with a clear message, not a swap storm, if it would exceed 12 GB.
- **First real round:** record its wall time and compare it with the 3–4 hour estimate in `train_log.json`.
- **Determinism:** the seed is in the config; record torch and NeMo versions.
- **NeMo `log_prediction`** is off, so no text reaches stdout (T6.2's log rule).

## Acceptance criteria
- `healing train --local --smoke` finishes 20 steps and writes a delta whose tensor names cover only the LoRA targets, in both the encoder and the joint. Killed and rerun, a run resumes from its checkpoint.
