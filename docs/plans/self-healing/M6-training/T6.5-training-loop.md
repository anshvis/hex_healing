# T6.5 - NeMo LoRA training loop

## Milestone
M6. **Covers:** AC-12. **Surface:** backend.

## Branch
`healing/m6-training`.

## Objective
`healing/healing/train/lora.py` does the following:
1. Loads the base `.nemo` for the M0-chosen architecture.
2. Attaches LoRA (rank 16, alpha 32, dropout 0.05) to the encoder's attention q/k/v/out and feed-forward linears, **and to the TDT predictor and joint linears** (D-14).
3. Freezes everything else.
4. Trains on T6.1's bundle with a `WeightedRandomSampler`.
5. Saves the LoRA delta alone (`safetensors`), plus a train log of loss and validation WER only, with no text.

## Context
- Promotes T0.4's proven `lora_tiny.py` attach and merge code instead of rewriting it.
- CUDA is the training target (T6.2). Locally, `--smoke` runs 20 steps on CPU. NeMo's TDT loss is unreliable on MPS (challenge finding 20).

## Domain model
Source: inferred.

- **Outputs:** `out/lora_delta.safetensors` and `out/train_log.json`.
