# T6.2 - Remote GPU runner (Modal) with explicit upload opt-in and cleanup

## Milestone
M6. **Covers:** AC-12, G-3, X-6. **Surface:** backend.

## Branch
`healing/m6-training`.

## Objective
`healing train --remote --allow-upload` does the following:
1. Uploads the prepared bundle to a fresh Modal volume. The bundle is the WAVs plus the manifest: your voice and words.
2. Runs T6.5's trainer on one GPU (an A10G or L4 is enough for LoRA on 0.6B).
3. Downloads the delta and log.
4. **Deletes the volume.**

Without `--allow-upload`, it refuses and makes no network call at all.

## Context
This is the only place personal data leaves the Mac (G-3). It must be explicit, minimal and cleaned up.

## Domain model
Source: inferred.
- **`$HEALING_HOME/remote/runs.jsonl`:** `{run_id, provider, volume, uploaded_bytes, started_at_ms, finished_at_ms, deleted_volume: bool, error}`.

## API
- **`healing train --remote [--allow-upload] [--provider modal]`**
- **Errors:**
  - no `--allow-upload` → exit 5, "refusing to upload personal audio without --allow-upload";
  - no Modal token → exit 6, naming `modal token new` (X-6: park);
  - a remote failure → still deletes the volume, then exits non-zero;
  - a failed delete → logs `deleted_volume: false` and prints the exact `modal volume delete <name>` command.
- **Side effects:** uploads, a GPU run, downloads.

## Decisions
- D-15: Modal first.
- The bundle is the train split only. Test sets are never uploaded, since evaluation runs locally in Hex's runtime (T3.3).

## Watch out for
- **Ctrl-C mid-run:** a `finally` deletes the volume.
- **Credentials** come from Modal's own config. Never store them in `healing`.
- **Cost:** print the estimated GPU minutes before starting, and stop after `--max-minutes` (default 60).
- **Logs outlive the volume.** NeMo's validation logs print predictions and references (your words) to Modal's app logs, which deleting the volume doesn't remove. Set NeMo's `log_prediction: false`, keep only loss and WER in stdout, and assert in the test that the runner's log filter drops any line containing manifest text.

## Acceptance criteria
- Without the flag: exit 5 and no network.
- With the flag and a token: a run completes, `deleted_volume: true`, and the delta is downloaded. **This live check is parked until you add a Modal token.**
