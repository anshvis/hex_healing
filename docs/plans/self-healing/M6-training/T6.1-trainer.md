# T6.1 - Training data: weighted, cluster-balanced manifest with self-distilled replay

## Milestone
M6. **Covers:** AC-12. **Surface:** backend.

## Branch
`healing/m6-training` (one PR for M6), base `dev`.

## Objective
`healing train prepare` builds the NeMo training manifest and audio bundle from the current train split. The data:
- has sample weights from T3.1 (strong and verified 1.0; weak only with `--include-weak`);
- is cluster-balanced: each storage cluster is capped at an effective weight of 3, so 50 copies of one phrase count as 3;
- has clips capped at 30 s (D-23). Longer hands-free dictations are cut at pauses with the meeting pause cutter's rules, or skipped;
- mixes in 20% **self-distilled replay**: 2,000 LibriSpeech train-clean-100 clips labelled with the **base model's own transcripts**, punctuation and casing included (D-25). This resists forgetting without teaching the model to drop formatting (challenge finding 12);
- never contains a test-set split-cluster (asserted).

The training loop itself is T6.5. It was split off after the challenge flagged that one task held both data and the loop and was too big for a standard tier.

## Domain model
Source: inferred.
- **Training manifest** (NeMo JSONL): `{audio_filepath, duration, text, weight}`.
  - `text` is `reference_text` with the punctuation and casing you produced. For replay, it's the base model's transcript.
  - `weight` is applied through a `WeightedRandomSampler`, because NeMo's ASR datasets have no per-sample loss weight.
- **Bundle:** `$HEALING_HOME/train/<round>/{manifest.jsonl, audio/*.wav, bundle.sha256}`.

## API
- **`healing train prepare [--include-weak] [--replay 0.2]`** → the bundle path and its sha. The registry records the sha as part of the snapshot.
- Replay's source is LibriSpeech train-clean-100 parquet already on disk (`$HEALING_HOME/cache/librispeech-train-clean-100`, or `--replay-source`); `prepare` never downloads it. **`healing sets fetch-librispeech [--dest DIR]`** fetches it (14 pinned shards, 6.43 GB; D-45).

## Watch out for
- **LoRA targets (D-31).** Encoder attention, feed-forward and joint linears only; the predictor LSTM has no linear layers and stays frozen. Changed predictor tensors have no round-trip proof yet.
- **What the model heard (found in M0, T0.2).** A kept recording is the clip before transcription padding. On every OS the model then saw it with zeros appended: up to the minimum duration, plus 400 ms for Unified (`pad_gguf_samples`). On Linux and Windows with Labs › Skip long pauses on, long pauses were also cut first (`whole_clip`). Training applies the same padding; pause cutting is left out, because a label's text doesn't depend on silence.
- **A test split-cluster in the manifest** fails the run with an assert. It is never silently dropped.
- **Text normalization** keeps punctuation and casing as the base model emits them. No lowercasing.
- **Replay transcripts** come from the base (v0) model, not the current one, so drift doesn't compound.

## Acceptance criteria
- On the fixture:
  - the effective cluster weight is ≤ 3;
  - replay is 20% ± 1%;
  - no test split-cluster;
  - weak clips are excluded by default;
  - a 75 s clip becomes pause-cut pieces of 30 s or less;
  - replay text has punctuation.
